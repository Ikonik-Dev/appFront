📗 Lexique JavaScript - Terminologie et concepts

Référence complète des termes et concepts JavaScript essentiels

🔤 Concepts de base

Variable

Conteneur nommé qui stocke une valeur. En JavaScript moderne, on utilise let et const pour déclarer des variables. 

let nom = "Alice";
const age = 25;
var ancienneVariable = "déprécié";

Fonction

Bloc de code réutilisable qui effectue une tâche spécifique. Peut recevoir des paramètres et retourner une valeur. 

function saluer(nom) {
  return `Bonjour ${nom}!`;
}

const saluerArrow = (nom) => `Bonjour ${nom}!`;

Objet

Collection de propriétés (clé-valeur) qui représente une entité. Structure de données fondamentale en JavaScript. 

const personne = {
  nom: "Alice",
  age: 25,
  saluer() {
    return `Je suis ${this.nom}`;
  }
};

Array (Tableau)

Liste ordonnée d'éléments. Chaque élément a un index numérique commençant à 0. 

const fruits = ["pomme", "banane", "orange"];
fruits.push("kiwi");
console.log(fruits[0]); // "pomme"

Scope (Portée)

Zone du code où une variable est accessible. JavaScript a une portée de fonction, de bloc et globale. 

let global = "accessible partout";

function exemple() {
  let locale = "accessible dans la fonction";
  if (true) {
    let bloc = "accessible dans le bloc";
  }
}

Closure (Fermeture)

Fonction qui a accès aux variables de sa portée externe, même après que cette portée soit fermée. 

function creerCompteur() {
  let count = 0;
  return function() {
    return ++count;
  };
}

const compteur = creerCompteur();
console.log(compteur()); // 1

🏷️ Types de données

String (Chaîne)

Type de données représentant du texte. Peut être créé avec des guillemets simples, doubles ou des template literals. 

const simple = 'Texte simple';
const double = "Texte double";
const template = `Texte avec ${variable}`;

Number (Nombre)

Type numérique qui représente les entiers et les nombres décimaux. JavaScript n'a qu'un seul type numérique. 

const entier = 42;
const decimal = 3.14;
const negatif = -10;
const infini = Infinity;

Boolean (Booléen)

Type logique qui ne peut avoir que deux valeurs : true ou false. Utilisé pour les conditions et la logique. 

const vrai = true;
const faux = false;
const resultat = 5 > 3; // true

Null

Valeur primitive qui représente intentionnellement l'absence de valeur. Différent de undefined. 

let valeur = null; // absence intentionnelle
console.log(typeof null); // "object" (quirk historique)

Undefined

Valeur par défaut des variables déclarées mais non initialisées, ou des propriétés inexistantes. 

let nonInitialisee;
console.log(nonInitialisee); // undefined
console.log(objet.proprieteInexistante); // undefined

Symbol

Type primitif unique introduit en ES6. Chaque Symbol est unique et peut servir comme clé de propriété d'objet. 

const sym1 = Symbol("description");
const sym2 = Symbol("description");
console.log(sym1 === sym2); // false

⏰ Programmation asynchrone

Callback

Fonction passée en paramètre à une autre fonction pour être exécutée plus tard, souvent après une opération asynchrone. 

function traiterDonnees(donnees, callback) {
  // Traitement...
  callback(resultat);
}

traiterDonnees(data, function(resultat) {
  console.log(resultat);
});

Promise

Objet représentant la completion future d'une opération asynchrone. Peut être dans l'état pending, fulfilled, ou rejected. 

const promesse = new Promise((resolve, reject) => {
  // Opération asynchrone
  if (succes) {
    resolve(resultat);
  } else {
    reject(erreur);
  }
});

Async/Await

Syntaxe moderne pour gérer les opérations asynchrones de manière plus lisible, basée sur les Promises. 

async function obtenirDonnees() {
  try {
    const response = await fetch('/api/data');
    const data = await response.json();
    return data;
  } catch (error) {
    console.error(error);
  }
}

Event Loop

Mécanisme qui permet à JavaScript de gérer les opérations asynchrones malgré son caractère single-threaded. 

console.log("1");
setTimeout(() => console.log("2"), 0);
console.log("3");
// Sortie: 1, 3, 2

🌐 DOM et événements

DOM (Document Object Model)

Interface de programmation qui représente la structure HTML comme un arbre d'objets JavaScript manipulables. 

const element = document.getElementById('monId');
element.textContent = 'Nouveau contenu';
element.classList.add('nouvelle-classe');

Event (Événement)

Action qui se produit dans le navigateur (clic, chargement, saisie) à laquelle on peut réagir avec des event listeners. 

button.addEventListener('click', function(event) {
  event.preventDefault();
  console.log('Bouton cliqué!');
});

Event Bubbling

Propagation d'un événement de l'élément cible vers ses parents dans l'arbre DOM. 

// L'événement remonte de l'enfant vers le parent
parent.addEventListener('click', () => {
  console.log('Parent cliqué');
});

enfant.addEventListener('click', (e) => {
  e.stopPropagation(); // Arrête la propagation
});

Selector (Sélecteur)

Chaîne de caractères utilisée pour cibler des éléments DOM via querySelector et querySelectorAll. 

const element = document.querySelector('.classe');
const elements = document.querySelectorAll('div p');
const byId = document.getElementById('monId');

🆕 ES6+ et concepts modernes

Arrow Function

Syntaxe concise pour définir des fonctions introduite en ES6. A un comportement différent avec le contexte 'this'. 

// Fonction traditionnelle
function add(a, b) { return a + b; }

// Arrow function
const add = (a, b) => a + b;
const square = x => x * x;

Destructuring

Syntaxe permettant d'extraire des valeurs d'objets ou de tableaux dans des variables distinctes. 

// Destructuring d'objet
const {nom, age} = personne;

// Destructuring de tableau
const [premier, second] = tableau;

Spread Operator (...)

Opérateur qui permet d'étendre un itérable (tableau, objet) dans un autre contexte. 

const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5]; // [1, 2, 3, 4, 5]

const obj = {a: 1, ...autreObj, b: 2};

Template Literal

Chaînes de caractères délimitées par des backticks permettant l'interpolation de variables et les chaînes multi-lignes. 

const nom = "Alice";
const message = `Bonjour ${nom}!
Comment allez-vous?`;

const html = `<div class="${classe}">
  ${contenu}
</div>`;

Module

Système d'organisation du code permettant d'importer et exporter des fonctionnalités entre fichiers. 

// Export
export const fonction = () => {};
export default class MaClasse {}

// Import
import { fonction } from './module.js';
import MaClasse from './module.js';

Class

Syntaxe moderne pour créer des constructeurs et gérer l'héritage, introduite en ES6 comme sucre syntaxique sur les prototypes. 

class Animal {
  constructor(nom) {
    this.nom = nom;
  }
  
  parler() {
    console.log(`${this.nom} fait du bruit`);
  }
}

class Chien extends Animal {
  parler() {
    console.log(`${this.nom} aboie`);
  }
}
