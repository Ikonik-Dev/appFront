📖 Lexique HTML - Dictionnaire des balises

Référence complète des balises HTML les plus couramment utilisées

🏗️ Balises de structure

<html>

Élément racine d'un document HTML. Contient tout le contenu de la page. 

<html lang="fr">
  <!-- Contenu de la page -->
</html>

<head>

Contient les métadonnées du document (titre, liens CSS, scripts, etc.). 

<head>
  <title>Titre de la page</title>
  <meta charset="UTF-8">
</head>

<body>

Contient tout le contenu visible de la page web. 

<body>
  <h1>Contenu visible</h1>
</body>

<header>

Représente l'en-tête d'une section ou d'une page. 

<header>
  <h1>Titre principal</h1>
  <nav>Navigation</nav>
</header>

<main>

Représente le contenu principal d'un document. 

<main>
  <article>Contenu principal</article>
</main>

<footer>

Représente le pied de page d'une section ou d'une page. 

<footer>
  <p>© 2023 Mon site</p>
</footer>

📝 Balises de titre

<h1> à <h6>

Définissent les titres de différents niveaux (h1 = plus important, h6 = moins important). 

<h1>Titre principal</h1>
<h2>Sous-titre</h2>
<h3>Titre de section</h3>
<h4>Titre de sous-section</h4>
<h5>Titre de niveau 5</h5>
<h6>Titre de niveau 6</h6>

📄 Balises de contenu

<p>

Définit un paragraphe de texte.

<p>Ceci est un paragraphe.</p>

<span>

Élément générique en ligne pour grouper du contenu. 

<p>Texte avec <span class="highlight">mise en évidence</span></p>

<div>

Élément générique de bloc pour grouper du contenu. 

<div class="container">
  <p>Contenu groupé</p>
</div>

<article>

Représente un contenu autonome et indépendant. 

<article>
  <h2>Titre de l'article</h2>
  <p>Contenu de l'article...</p>
</article>

<section>

Représente une section générique d'un document. 

<section>
  <h2>Titre de la section</h2>
  <p>Contenu...</p>
</section>

✨ Balises de mise en forme

<strong>

Indique une importance forte (texte en gras). 

<p>Ceci est <strong>très important</strong>.</p>

<em>

Indique une emphase (texte en italique). 

<p>Ceci est <em>emphase</em>.</p>

<code>

Représente du code informatique.

<p>Utilisez <code>console.log()</code> pour débugger.</p>

<pre>

Texte préformaté qui preserve les espaces et sauts de ligne. 

<pre>
function hello() {
    console.log("Hello!");
}
</pre>

📋 Balises de listes

<ul>

Liste non ordonnée (à puces).

<ul>
  <li>Premier élément</li>
  <li>Deuxième élément</li>
</ul>

<ol>

Liste ordonnée (numérotée).

<ol>
  <li>Premier élément</li>
  <li>Deuxième élément</li>
</ol>

<li>

Élément de liste.

<ul>
  <li>Élément de liste</li>
</ul>

🔗 Balises de liens et médias

<a>

Crée un lien hypertexte.

<a href="https://example.com">Lien externe</a>
<a href="#section">Lien interne</a>

<img>

Insère une image (balise auto-fermante). 

<img src="image.jpg" alt="Description de l'image">

<video>

Insère une vidéo.

<video controls>
  <source src="video.mp4" type="video/mp4">
</video>

<audio>

Insère un fichier audio.

<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
</audio>

📝 Balises de formulaire

<form>

Crée un formulaire pour collecter des données. 

<form action="/submit" method="post">
  <!-- Champs du formulaire -->
</form>

<input>

Champ de saisie (texte, email, mot de passe, etc.). 

<input type="text" placeholder="Votre nom">
<input type="email" required>
<input type="password">

<textarea>

Zone de texte multi-lignes.

<textarea rows="4" cols="50">
Texte par défaut...
</textarea>

<select>

Liste déroulante de sélection.

<select>
  <option value="1">Option 1</option>
  <option value="2">Option 2</option>
</select>

<button>

Bouton cliquable.

<button type="submit">Envoyer</button>
<button type="button">Annuler</button>

<label>

Étiquette pour un champ de formulaire.

<label for="nom">Nom :</label>
<input type="text" id="nom">

📊 Balises de tableau

<table>

Crée un tableau.

<table>
  <thead>...</thead>
  <tbody>...</tbody>
</table>

<tr>

Ligne de tableau.

<tr>
  <td>Cellule 1</td>
  <td>Cellule 2</td>
</tr>

<td>

Cellule de données dans un tableau.

<td>Contenu de la cellule</td>

<th>

Cellule d'en-tête de tableau.

<th>Titre de colonne</th>
