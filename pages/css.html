Variables CSS (Custom Properties)

Propriétés personnalisées pour un CSS maintenable et dynamique

Définition et utilisation

Changer le thème :

Carte avec thème dynamique

Les couleurs changent grâce aux variables CSS


/* Définition des variables dans :root */
:root {
    --primary-color: #4facfe;
    --secondary-color: #00f2fe;
    --border-radius: 12px;
    --spacing: 1rem;
}

/* Utilisation des variables */
.themed-card {
    background: linear-gradient(135deg, var(--primary-color), var(--secondary-color));
    border-radius: var(--border-radius);
    padding: var(--spacing);
}

/* Changement dynamique avec JavaScript */
document.documentElement.style.setProperty('--primary-color', '#ff6b6b');
