🚀 Introduction au CSS

CSS (Cascading Style Sheets) est le langage utilisé pour décrire la présentation d'un document HTML. Il contrôle les couleurs, les polices, la mise en page et l'apparence générale.

Comment ajouter du CSS ?

Il existe trois façons d'ajouter du CSS à votre HTML :

1. CSS inline (dans la balise) :

<p style="color: blue; font-size: 16px;">Texte bleu</p>

2. CSS interne (dans le head) :

<style>
p {
    color: blue;
    font-size: 16px;
}
</style>

3. CSS externe (fichier séparé) :

<link rel="stylesheet" href="styles.css">

🎯 Sélecteurs CSS

Sélecteurs de base

/* Sélecteur d'élément */
h1 {
    color: red;
}

/* Sélecteur de classe */
.ma-classe {
    background-color: yellow;
}

/* Sélecteur d'ID */
#mon-id {
    font-weight: bold;
}

/* Sélecteur universel */
* {
    margin: 0;
    padding: 0;
}

Sélecteurs combinés

/* Descendant */
div p {
    color: blue;
}

/* Enfant direct */
div > p {
    margin-left: 20px;
}

/* Plusieurs classes */
.classe1.classe2 {
    border: 1px solid black;
}

🎨 Propriétés de style essentielles

Couleurs et arrière-plans

.exemple {
    color: #ff0000;                    /* Couleur du texte */
    background-color: rgb(255, 255, 0); /* Couleur de fond */
    background-image: url('image.jpg'); /* Image de fond */
    background-size: cover;             /* Taille de l'image */
    background-position: center;        /* Position de l'image */
}

Police et texte

.texte {
    font-family: Arial, sans-serif;  /* Police */
    font-size: 16px;                 /* Taille */
    font-weight: bold;               /* Épaisseur */
    text-align: center;              /* Alignement */
    text-decoration: underline;      /* Décoration */
    line-height: 1.5;               /* Interligne */
}

📦 Modèle de boîte (Box Model)

Chaque élément HTML est une boîte composée de :

.boite {
    width: 300px;           /* Largeur du contenu */
    height: 200px;          /* Hauteur du contenu */
    padding: 20px;          /* Espacement interne */
    border: 2px solid red;  /* Bordure */
    margin: 10px;           /* Espacement externe */
}

Propriétés de bordure

.bordures {
    border-width: 2px;
    border-style: solid;  /* solid, dashed, dotted */
    border-color: blue;
    
    /* Raccourci */
    border: 2px solid blue;
    
    /* Bordures individuelles */
    border-top: 1px solid red;
    border-radius: 10px;  /* Coins arrondis */
}

📐 Mise en page avec Flexbox

Flexbox est un système de mise en page moderne et flexible :

Container flex :

.container {
    display: flex;
    justify-content: center;    /* Alignement horizontal */
    align-items: center;        /* Alignement vertical */
    flex-direction: row;        /* Direction des éléments */
    flex-wrap: wrap;           /* Retour à la ligne */
}

Éléments flex :

.element {
    flex: 1;          /* Prend l'espace disponible */
    flex-grow: 1;     /* Facteur de croissance */
    flex-shrink: 1;   /* Facteur de rétrécissement */
    flex-basis: auto; /* Taille de base */
}

📱 Responsive Design

Utilisez les media queries pour adapter votre design aux différentes tailles d'écran : 

/* Desktop first */
.element {
    width: 50%;
}

/* Tablette */
@media (max-width: 768px) {
    .element {
        width: 70%;
    }
}

/* Mobile */
@media (max-width: 480px) {
    .element {
        width: 100%;
    }
}

🎯 Points clés à retenir

  • CSS sépare le contenu de la présentation
  • Les sélecteurs définissent quels éléments styliser
  • Le modèle de boîte détermine l'espace occupé
  • Flexbox simplifie la mise en page
  • Les media queries permettent le responsive design
  • Toujours tester sur différents navigateurs

🚀 CSS Grid - Mise en page avancée

CSS Grid est un système de mise en page bidimensionnel plus puissant que Flexbox pour les layouts complexes.

Grid de base

.container-grid {
    display: grid;
    grid-template-columns: 1fr 2fr 1fr;  /* 3 colonnes */
    grid-template-rows: auto 1fr auto;   /* 3 lignes */
    grid-gap: 20px;                      /* Espacement */
    height: 100vh;
}

.header {
    grid-column: 1 / -1;  /* De la première à la dernière colonne */
    background: #f0f0f0;
}

.sidebar {
    grid-column: 1;
    grid-row: 2;
    background: #e0e0e0;
}

.main-content {
    grid-column: 2;
    grid-row: 2;
    background: #fff;
}

.aside {
    grid-column: 3;
    grid-row: 2;
    background: #e0e0e0;
}

.footer {
    grid-column: 1 / -1;
    background: #d0d0d0;
}

Grid avec zones nommées

.layout-grid {
    display: grid;
    grid-template-areas: 
        "header header header"
        "nav main aside"
        "footer footer footer";
    grid-template-columns: 200px 1fr 200px;
    grid-template-rows: auto 1fr auto;
    gap: 10px;
    min-height: 100vh;
}

.header { grid-area: header; }
.nav    { grid-area: nav; }
.main   { grid-area: main; }
.aside  { grid-area: aside; }
.footer { grid-area: footer; }

/* Responsive avec Grid */
@media (max-width: 768px) {
    .layout-grid {
        grid-template-areas: 
            "header"
            "nav"
            "main"
            "aside"
            "footer";
        grid-template-columns: 1fr;
    }
}

    --couleur-fond: #2c3e50;
    --couleur-texte: #ecf0f1;

.bouton {
    background-color: var(--couleur-primaire);
    padding: var(--espacement-md);
    font-family: var(--police-principale);
    box-shadow: var(--ombre-legere);

.container {
    --largeur-base: 300px;
    --ratio: 1.5;
    width: calc(var(--largeur-base) * var(--ratio));
    margin: calc(var(--espacement-lg) * 2) auto;
}

Fonctions CSS modernes

/* Fonction clamp() pour du responsive fluide */
.titre {
    font-size: clamp(1.5rem, 4vw, 3rem);
    /* Minimum 1.5rem, idéal 4vw, maximum 3rem */
}

/* Fonction min() et max() */
.sidebar {
    width: min(300px, 25vw);  /* Plus petit des deux */
    max-width: max(250px, 20vw);  /* Plus grand des deux */
}

/* Fonctions de couleur */
.element {
    background: hsl(200, 50%, 50%);
    border: 1px solid hsl(200, 50%, 30%);  /* Version plus sombre */
}

/* Nouveau : Fonction color-mix() */
.bouton-moderne {
    background: color-mix(in srgb, var(--couleur-primaire) 80%, white);
    border: 1px solid color-mix(in srgb, var(--couleur-primaire) 60%, black);
}

/* Dégradés avec calc() */
.barre-progression {
    background: linear-gradient(
        to right,
        var(--couleur-primaire) calc(var(--progression) * 1%),
        #f0f0f0 calc(var(--progression) * 1%)
    );
}
