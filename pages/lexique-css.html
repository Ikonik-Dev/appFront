📚 Lexique CSS - Dictionnaire des propriétés

Référence complète des propriétés CSS les plus couramment utilisées

📐 Propriétés de mise en page

display

Définit le type d'affichage d'un élément (block, inline, flex, grid, etc.). 

.element {
  display: block;      /* Élément de bloc */
  display: inline;     /* Élément en ligne */
  display: flex;       /* Conteneur flexible */
  display: grid;       /* Grille CSS */
  display: none;       /* Masqué */
}

position

Définit la méthode de positionnement d'un élément. 

.element {
  position: static;    /* Par défaut */
  position: relative;  /* Relatif à sa position normale */
  position: absolute;  /* Absolue par rapport au parent */
  position: fixed;     /* Fixe par rapport à la fenêtre */
  position: sticky;    /* Collant */
}

float

Fait flotter un élément à gauche ou à droite. 

.element {
  float: left;   /* Flotte à gauche */
  float: right;  /* Flotte à droite */
  float: none;   /* Pas de flottement */
}

clear

Annule l'effet de flottement des éléments précédents. 

.element {
  clear: left;   /* Annule float: left */
  clear: right;  /* Annule float: right */
  clear: both;   /* Annule tous les flottements */
}

📏 Propriétés de dimension

width

Définit la largeur d'un élément.

.element {
  width: 100px;     /* Largeur fixe */
  width: 50%;       /* Largeur relative */
  width: auto;      /* Largeur automatique */
  width: 100vw;     /* 100% de la viewport */
}

height

Définit la hauteur d'un élément.

.element {
  height: 200px;    /* Hauteur fixe */
  height: 50%;      /* Hauteur relative */
  height: auto;     /* Hauteur automatique */
  height: 100vh;    /* 100% de la viewport */
}

min-width / max-width

Définit la largeur minimale/maximale d'un élément. 

.element {
  min-width: 200px;   /* Largeur minimale */
  max-width: 800px;   /* Largeur maximale */
}

min-height / max-height

Définit la hauteur minimale/maximale d'un élément. 

.element {
  min-height: 100px;  /* Hauteur minimale */
  max-height: 500px;  /* Hauteur maximale */
}

📦 Propriétés d'espacement

margin

Définit l'espace externe autour d'un élément. 

.element {
  margin: 10px;              /* Toutes les directions */
  margin: 10px 20px;         /* Vertical | Horizontal */
  margin: 10px 20px 15px;    /* Haut | H | Bas */
  margin: 10px 20px 15px 5px; /* H | D | B | G */
  margin-top: 10px;
  margin-right: 20px;
  margin-bottom: 15px;
  margin-left: 5px;
}

padding

Définit l'espace interne à l'intérieur d'un élément. 

.element {
  padding: 10px;              /* Toutes les directions */
  padding: 10px 20px;         /* Vertical | Horizontal */
  padding: 10px 20px 15px;    /* Haut | H | Bas */
  padding: 10px 20px 15px 5px; /* H | D | B | G */
  padding-top: 10px;
  padding-right: 20px;
  padding-bottom: 15px;
  padding-left: 5px;
}

🎨 Propriétés de couleur et fond

color

Définit la couleur du texte.

.element {
  color: red;               /* Nom de couleur */
  color: #ff0000;           /* Hexadécimal */
  color: rgb(255, 0, 0);    /* RGB */
  color: rgba(255, 0, 0, 0.5); /* RGBA avec transparence */
  color: hsl(0, 100%, 50%); /* HSL */
}

background-color

Définit la couleur d'arrière-plan.

.element {
  background-color: blue;
  background-color: #0066cc;
  background-color: rgba(0, 102, 204, 0.8);
}

background-image

Définit une image d'arrière-plan.

.element {
  background-image: url('image.jpg');
  background-image: linear-gradient(to right, red, blue);
  background-image: radial-gradient(circle, red, blue);
}

background-size

Définit la taille de l'image d'arrière-plan. 

.element {
  background-size: cover;    /* Couvre tout l'élément */
  background-size: contain;  /* Contient dans l'élément */
  background-size: 100px 200px; /* Taille spécifique */
  background-size: 50%;      /* Pourcentage */
}

📝 Propriétés de texte

font-family

Définit la famille de police.

.element {
  font-family: 'Arial', sans-serif;
  font-family: 'Times New Roman', serif;
  font-family: 'Courier New', monospace;
}

font-size

Définit la taille de la police.

.element {
  font-size: 16px;    /* Pixels */
  font-size: 1.2em;   /* Em (relatif au parent) */
  font-size: 1.5rem;  /* Rem (relatif à la racine) */
  font-size: large;   /* Mots-clés */
}

font-weight

Définit l'épaisseur de la police.

.element {
  font-weight: normal;  /* 400 */
  font-weight: bold;    /* 700 */
  font-weight: 100;     /* Très fin */
  font-weight: 900;     /* Très gras */
}

text-align

Définit l'alignement horizontal du texte. 

.element {
  text-align: left;     /* À gauche */
  text-align: center;   /* Centré */
  text-align: right;    /* À droite */
  text-align: justify;  /* Justifié */
}

text-decoration

Ajoute des décorations au texte.

.element {
  text-decoration: none;        /* Aucune */
  text-decoration: underline;   /* Souligné */
  text-decoration: overline;    /* Ligne au-dessus */
  text-decoration: line-through; /* Barré */
}

line-height

Définit la hauteur de ligne.

.element {
  line-height: 1.5;     /* Multiplicateur */
  line-height: 24px;    /* Valeur fixe */
  line-height: 150%;    /* Pourcentage */
}

🔲 Propriétés de bordure

border

Définit une bordure complète (raccourci). 

.element {
  border: 1px solid black;           /* Épaisseur Style Couleur */
  border: 2px dashed red;
  border: 3px dotted blue;
  border-top: 1px solid black;       /* Bordure spécifique */
  border-right: 2px dashed red;
  border-bottom: 3px dotted blue;
  border-left: 1px solid green;
}

border-radius

Arrondit les coins d'un élément.

.element {
  border-radius: 10px;              /* Tous les coins */
  border-radius: 10px 20px;         /* Haut-gauche/Bas-droite | Autres */
  border-radius: 10px 20px 30px 40px; /* HG | HD | BD | BG */
  border-radius: 50%;               /* Cercle parfait */
}

box-shadow

Ajoute une ombre à un élément.

.element {
  box-shadow: 2px 2px 4px rgba(0,0,0,0.3);
  /* Offset-X | Offset-Y | Blur | Couleur */
  
  box-shadow: 0 4px 8px rgba(0,0,0,0.2),
              0 6px 20px rgba(0,0,0,0.1);
  /* Ombres multiples */
}

🔧 Propriétés Flexbox

justify-content

Aligne les éléments flexibles sur l'axe principal. 

.flex-container {
  display: flex;
  justify-content: flex-start;   /* Début */
  justify-content: center;       /* Centre */
  justify-content: flex-end;     /* Fin */
  justify-content: space-between; /* Espacement égal */
  justify-content: space-around;  /* Espacement autour */
}

align-items

Aligne les éléments flexibles sur l'axe secondaire. 

.flex-container {
  display: flex;
  align-items: stretch;    /* Étire (par défaut) */
  align-items: flex-start; /* Début */
  align-items: center;     /* Centre */
  align-items: flex-end;   /* Fin */
  align-items: baseline;   /* Ligne de base */
}

flex-direction

Définit la direction des éléments flexibles. 

.flex-container {
  display: flex;
  flex-direction: row;            /* Ligne (par défaut) */
  flex-direction: row-reverse;    /* Ligne inversée */
  flex-direction: column;         /* Colonne */
  flex-direction: column-reverse; /* Colonne inversée */
}

flex-wrap

Contrôle si les éléments flexibles peuvent passer à la ligne. 

.flex-container {
  display: flex;
  flex-wrap: nowrap;     /* Pas de retour à la ligne */
  flex-wrap: wrap;       /* Retour à la ligne */
  flex-wrap: wrap-reverse; /* Retour à la ligne inversé */
}

🎬 Propriétés d'animation

transition

Crée une transition fluide entre les états. 

.element {
  transition: all 0.3s ease;
  /* Propriété | Durée | Fonction de timing */
  
  transition: color 0.5s ease-in-out,
              background-color 0.3s linear;
  /* Transitions multiples */
}

transform

Applique des transformations 2D ou 3D.

.element {
  transform: translateX(50px);     /* Translation */
  transform: rotate(45deg);        /* Rotation */
  transform: scale(1.5);           /* Mise à l'échelle */
  transform: skew(20deg);          /* Inclinaison */
  
  /* Transformations combinées */
  transform: translate(50px, 100px) rotate(45deg) scale(1.2);
}

opacity

Définit la transparence d'un élément.

.element {
  opacity: 1;     /* Complètement opaque */
  opacity: 0.5;   /* Semi-transparent */
  opacity: 0;     /* Complètement transparent */
}
