/* Orientation */
@media (orientation: portrait) {
    .content { padding: 1rem; }
}

@media (orientation: landscape) {
    .content { padding: 2rem 4rem; }
}

/* Type de média */
@media print {
    .no-print { display: none; }
    body { color: black; background: white; }
}

/* Préférences utilisateur */
@media (prefers-reduced-motion: reduce) {
    * { animation-duration: 0.01ms !important; }
}

@media (prefers-color-scheme: dark) {
    body { background: #1a1a1a; color: white; }
}

/* Résolution d'écran */
@media (-webkit-min-device-pixel-ratio: 2) {
    .high-res-image { background-image: url('image@2x.png'); }
}

/* Largeur de viewport complexe */
@media (min-width: 768px) and (max-width: 1024px) {
    .tablet-specific { display: block; }
}

/* Image fluide basique */
.responsive-image {
    max-width: 100%;
    height: auto;
    display: block;
}

/* Avec srcset pour différentes résolutions */
<img 
    src="image-400.jpg"
    srcset="image-400.jpg 400w, 
            image-800.jpg 800w, 
            image-1200.jpg 1200w"
    sizes="(max-width: 768px) 100vw, 
           (max-width: 1024px) 50vw, 
           33vw"
    alt="Description"
>

/* Art direction avec picture */
<picture>
    <source 
        media="(min-width: 768px)" 
        srcset="desktop-image.jpg"
    >
    <img src="mobile-image.jpg" alt="Description">
</picture>

/* Images de fond responsive */
.bg-responsive {
    background-image: url('mobile-bg.jpg');
    background-size: cover;
    background-position: center;
}

@media (min-width: 768px) {
    .bg-responsive {
        background-image: url('desktop-bg.jpg');
    }
}

Typographie Responsive

Adaptation fluide des tailles de texte et de l'espacement

Unités fluides et clamp()

Titre Fluide

Ce texte utilise des unités fluides pour s'adapter automatiquement à la taille de l'écran. La fonction clamp() permet de définir des valeurs minimum, préférée et maximum.

Tester différentes approches :

Échelle typographique

Sous-titre

Titre de section

Paragraphe normal avec du texte de longueur moyenne

Texte en petite taille 

/* Typographie fluide avec clamp() */
.fluid-title {
    font-size: clamp(2rem, 5vw, 4rem);
    /* min: 2rem, préféré: 5vw, max: 4rem */
}

.fluid-text {
    font-size: clamp(1rem, 2.5vw, 1.25rem);
    line-height: clamp(1.4, 1.5vw, 1.6);
}

/* Approche par breakpoints */
.responsive-title {
    font-size: 2rem;
}

@media (min-width: 768px) {
    .responsive-title {
        font-size: 3rem;
    }
}

@media (min-width: 1024px) {
    .responsive-title {
        font-size: 4rem;
    }
}

/* Espacement fluide */
.container {
    padding: clamp(1rem, 5vw, 3rem);
    margin-bottom: clamp(2rem, 8vw, 6rem);
}

/* Variables CSS pour la cohérence */
:root {
    --font-size-sm: clamp(0.875rem, 2vw, 1rem);
    --font-size-base: clamp(1rem, 2.5vw, 1.125rem);
    --font-size-lg: clamp(1.25rem, 3vw, 1.5rem);
    --font-size-xl: clamp(2rem, 5vw, 3rem);
}
