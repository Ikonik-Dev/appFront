🚀 Introduction au HTML

HTML (HyperText Markup Language) est le langage de balisage standard pour créer des pages web. Il décrit la structure et le contenu d'une page web à l'aide de balises.

Qu'est-ce qu'une balise ?

Une balise HTML est un élément qui indique au navigateur comment afficher le contenu. Les balises sont entourées de crochets angulaires <>.

Exemple de balise :

<h1>Ceci est un titre</h1>
<p>Ceci est un paragraphe</p>

🏗️ Structure de base d'un document HTML

Chaque document HTML doit avoir une structure de base :

<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Titre de la page</title>
</head>
<body>
    <h1>Contenu de la page</h1>
</body>
</html>

Explication des éléments :

  • <!DOCTYPE html> : Déclare le type de document
  • <html> : Élément racine du document
  • <head> : Contient les métadonnées
  • <body> : Contient le contenu visible

📝 Balises de contenu essentielles

Titres et paragraphes

<h1>Titre principal</h1>
<h2>Sous-titre</h2>
<h3>Titre de niveau 3</h3>
<p>Un paragraphe de texte.</p>

Formatage du texte

<strong>Texte en gras</strong>
<em>Texte en italique</em>
<u>Texte souligné</u>
<code>Code informatique</code>

Listes

Liste non ordonnée :

<ul>
    <li>Premier élément</li>
    <li>Deuxième élément</li>
</ul>

Liste ordonnée :

<ol>
    <li>Premier élément</li>
    <li>Deuxième élément</li>
</ol>

🔗 Liens et images

Créer des liens

<a href="https://www.example.com">Lien externe</a>
<a href="page.html">Lien interne</a>
<a href="#section">Lien vers une section</a>

Insérer des images

<img src="image.jpg" alt="Description de l'image">

Important : L'attribut alt est essentiel pour l'accessibilité.

🎯 Points clés à retenir

  • HTML structure le contenu avec des balises
  • Chaque balise ouvrante doit avoir une balise fermante
  • Les attributs donnent des informations supplémentaires
  • L'indentation améliore la lisibilité du code
  • Toujours valider votre HTML

🚀 Concepts intermédiaires - HTML Sémantique

Le HTML sémantique utilise des balises qui ont une signification précise, améliorant l'accessibilité et le SEO.

Balises sémantiques HTML5

<header>
    <nav>
        <ul>
            <li><a href="#accueil">Accueil</a></li>
            <li><a href="#services">Services</a></li>
        </ul>
    </nav>
</header>

<main>
    <article>
        <header>
            <h1>Titre de l'article</h1>
            <time datetime="2025-08-20">20 août 2025</time>
        </header>
        
        <section>
            <h2>Introduction</h2>
            <p>Contenu de l'article...</p>
        </section>
        
        <aside>
            <h3>Info complémentaire</h3>
            <p>Informations connexes...</p>
        </aside>
    </article>
</main>

<footer>
    <p>© 2025 Mon Site Web</p>
</footer>

Pourquoi utiliser la sémantique ?

  • SEO amélioré : Les moteurs de recherche comprennent mieux votre contenu
  • Accessibilité : Les lecteurs d'écran naviguent plus facilement
  • Maintenance : Le code est plus lisible et organisé
  • Future-proof : Compatible avec les futures technologies

⚡ Attributs avancés et métadonnées

Attributs data-* personnalisés

Permettent de stocker des données personnalisées dans les éléments HTML. 

<div class="produit" 
     data-prix="29.99" 
     data-categorie="electronique" 
     data-stock="15">
    Smartphone XYZ
</div>

<script>
// Accès via JavaScript
const produit = document.querySelector('.produit');
console.log(produit.dataset.prix); // "29.99"
console.log(produit.dataset.categorie); // "electronique"
</script>

Métadonnées et Open Graph

<head>
    <!-- SEO de base -->
    <meta name="description" content="Description de la page pour les moteurs de recherche">
    <meta name="keywords" content="html, sémantique, web, développement">
    
    <!-- Open Graph pour les réseaux sociaux -->
    <meta property="og:title" content="Titre affiché sur Facebook/Twitter">
    <meta property="og:description" content="Description pour le partage social">
    <meta property="og:image" content="https://monsite.com/image-partage.jpg">
    <meta property="og:url" content="https://monsite.com/page">
    
    <!-- Twitter Cards -->
    <meta name="twitter:card" content="summary_large_image">
    <meta name="twitter:title" content="Titre pour Twitter">
</head>

🎨 Formulaires avancés

Types d'input modernes

<form>
    <!-- Input avec validation native -->
    <label for="email">Email :</label>
    <input type="email" id="email" required 
           placeholder="votre@email.com"
           pattern="[a-z0-9._%+-]+@[a-z0-9.-]+\.[a-z]{2,}$">
    
    <!-- Input numérique avec contraintes -->
    <label for="age">Âge :</label>
    <input type="number" id="age" min="0" max="120" step="1">
    
    <!-- Input date et couleur -->
    <label for="naissance">Date de naissance :</label>
    <input type="date" id="naissance">
    
    <label for="couleur">Couleur préférée :</label>
    <input type="color" id="couleur">
    
    <!-- Slider et range -->
    <label for="volume">Volume : <span id="volume-valeur"></span></label>
    <input type="range" id="volume" min="0" max="100" value="50"
           oninput="document.getElementById('volume-valeur').textContent = this.value">
</form>

🔧 Techniques avancées

Web Components et Custom Elements

Introduction aux composants personnalisés HTML modernes :

<!-- Utilisation d'un composant personnalisé -->
<mon-composant titre="Hello World" couleur="bleu">
    <p slot="contenu">Contenu du composant</p>
</mon-composant>

<script>
class MonComposant extends HTMLElement {
    constructor() {
        super();
        this.attachShadow({ mode: 'open' });
    }
    
    connectedCallback() {
        const titre = this.getAttribute('titre');
        const couleur = this.getAttribute('couleur');
        
        this.shadowRoot.innerHTML = \`
            <style>
                .composant { color: \${couleur}; }
            </style>
            <div class="composant">
                <h3>\${titre}</h3>
                <slot name="contenu"></slot>
            </div>
        \`;
    }
}

customElements.define('mon-composant', MonComposant);
</script>
